1. 📝 Crea una cuenta en NVIDIA NGC (si no tienes)
Ve a: https://ngc.nvidia.com/signin

Regístrate o inicia sesión

2. 🔐 Genera un API key (token)
Una vez dentro, ve a NGC API Key

Haz clic en “Generate API Key”

Guarda el token

3. 🔓 Haz login en nvcr.io desde la terminal
Ejecuta:

bash
Copiar
Editar
docker login nvcr.io
Te pedirá:

Username: tu correo de NGC (o simplemente \$oauthtoken)

Password: el API Key generado

En general funciona mejor si pones \$oauthtoken como usuario, y el token como password:

bash
Copiar
Editar
Username: $oauthtoken
Password: <el token que generaste>
4. 🔄 Luego vuelve a correr tu build:
bash
Copiar
Editar
docker buildx build --platform linux/arm64 -t skaion:v1 .
